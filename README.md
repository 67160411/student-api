# ขั้นตอนที่ 3.2 ทบทวนคุณภาพของโค้ด

## พิจารณาคำถามต่อไปนี้ร่วมกับเพื่อนในชั้นเรียนหรือผู้สอน (Peer Review เบื้องต้น)

### 1.โค้ดใน index.js มีการตรวจสอบข้อมูลนำเข้า (validation) ก่อนประมวลผลหรือไม่

มีการตรวจสอบข้อมูลนำเข้าในส่วนของ POST และ PUT โดยเช็กว่ามี 'name' และ 'major' ครบหรือไม่ หากไม่ครบจะส่ง Status Code 400 กลับไป

---

### 2.ทุก route มีการตอบกลับด้วย Status Code ที่เหมาะสมกับผลลัพธ์หรือไม่

มีการใช้ Status Code เหมาะสม เช่น 200 สำหรับสำเร็จ, 201 สำหรับเพิ่มข้อมูล, 400 สำหรับข้อมูลไม่ถูกต้อง และ 404 สำหรับไม่พบข้อมูล

---

### 3.โครงสร้างโค้ดในไฟล์เดียวยังอ่านง่ายอยู่หรือไม่ หากมี route เพิ่มขึ้นอีก 10 เส้นทาง จะเกิดปัญหาใดตามมา

ตอนนี้ยังอ่านง่ายเพราะมี Route ไม่เยอะ แต่ถ้าเพิ่มมากขึ้นไฟล์จะยาวและดูแลยาก ควรแยก Route, Controller และส่วนต่าง ๆ ออกจากกันเพื่อจัดการง่ายขึ้นในอนาคต
