# URI Schema - Student API

| Method | URI                        | คำอธิบาย                                            | Status Code ที่เป็นไปได้ |
| ------ | -------------------------- | --------------------------------------------------- | ------------------------ |
| GET    | /                          | ตรวจสอบสถานะ Student API                            | 200                      |
| GET    | /api/v1/students           | ดึงรายการนักศึกษาทั้งหมด                                | 200                      |
| GET    | /api/v1/students/{id}      | ดึงข้อมูลนักศึกษารายบุคคล (รองรับ ?include=courses)       | 200, 404                 |
| POST   | /api/v1/students           | เพิ่มข้อมูลนักศึกษาใหม่                                   | 201, 400, 409            |
| PUT    | /api/v1/students/{id}      | แก้ไขข้อมูลนักศึกษาทั้งระเบียน                             | 200, 400, 404            |
| PATCH  | /api/v1/students/{id}      | แก้ไขข้อมูลนักศึกษาบางส่วน                               | 200, 404                 |
| DELETE | /api/v1/students/{id}      | ลบข้อมูลนักศึกษา                                       | 200, 404                 |
| GET    | /api/v1/students/{id}/full | ดึงข้อมูลนักศึกษาพร้อมรายวิชาที่ลงทะเบียน                    | 200, 404                 |
| POST   | /graphql                   | เรียกใช้งาน GraphQL Endpoint                           | 200                      |
